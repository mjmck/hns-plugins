Put the join sound source files here (`vip.wav`, 44.1 kHz or 48 kHz, 16-bit; `.mp3` also works).
Workshop Tools compiles `sounds/hns/join/vip.wav` to `vip.vsnd_c`; the soundevents file refers to it as `sounds/hns/join/vip.vsnd`.
Keep each clip short (2-4 s) and normalised to about -1 dBFS peak: the event plays at full volume for everyone.
